# eListam
Work-in-Progress (WIP): eListam will be a Point Of Sale (POS) web application to be developed using React.js, Bootstrap, ASP.NET Core Web API, and Microsoft SQL Server.

---

## Progress
- Organized components and pages for better folder structure and separation of concerns
- Used React Components, Hooks, Context API, and React Router for reusability, prop drilling elimination, and navigation
- Seeded dummy items through an external API call
- Implemented Clean Architecture, Dependency Injection, Repository Pattern, and Results Pattern for scalability and maintainability
- Utilized JWT Authentication
- Added Global Exception Handler
- Created feature branch called "main-api-integration" for API integration changes
